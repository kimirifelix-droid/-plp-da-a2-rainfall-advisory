# Rainfall Advisory Analysis

## Project Summary

This project analyzes monthly rainfall data for five Kenyan counties: Nairobi, Nakuru, Kisumu, Mombasa, and Machakos. The analysis uses Python and NumPy to clean rainfall data, calculate annual totals and monthly averages, identify wettest and dry months, and determine the best two-month planting window.

## How to Run

1. Activate the virtual environment.
2. Start Jupyter Notebook with: jupyter notebook
3. Open rainfall_analysis.ipynb.
4. Restart the kernel and run all cells from top to bottom.
5. Confirm that the analysis outputs and rainfall_summary.csv are generated.

## Planting Advisory

- **Nairobi:** Prioritize planting around April-May when rainfall is strongest.
- **Nakuru:** Prioritize planting around April-May when rainfall is strongest.
- **Kisumu:** Prioritize planting around April-May when rainfall is strongest.
- **Mombasa:** Prioritize planting around April-May when rainfall is strongest.
- **Machakos:** Prioritize planting around November-December when rainfall is strongest.
